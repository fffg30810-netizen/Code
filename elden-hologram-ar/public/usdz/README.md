# USDZ per Quick Look (iOS, opzionale)

Safari su iPhone/iPad non supporta WebXR: oltre alla "Modalità Camera" dell'app puoi offrire
l'AR nativa di Apple mettendo qui `<id>.usdz` (es. `malenia.usdz`). La schermata iniziale
mostrerà i link Quick Look per i file presenti (un boss alla volta, senza combattimento).

Conversione GLB → USDZ: Reality Converter (macOS), `usdzconvert` (USD Python tools) o Blender 4.x
(File → Export → USD, formato .usdz). Le animazioni skinnate sono supportate da Quick Look.
